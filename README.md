# WebcamViewer

Простое iOS-приложение: список публичных веб-камер, каждая открывается во
встроенном веб-просмотрщике. Кнопка звука есть, но реально работает только
если у конкретной камеры звук есть в принципе (у большинства публичных камер
его нет — это ограничение источника, а не приложения).

## Как собрать (так же, как в прошлый раз)

1. Залей эту папку в свой GitHub-репозиторий (ветка `main`).
2. Открой вкладку **Actions** → workflow **Build IPA** → **Run workflow**
   (или просто запушь в `main`, он запустится сам).
3. Дождись зелёной галочки, открой запуск, внизу в разделе **Artifacts**
   скачай `WebcamViewer-ipa`, распакуй zip — внутри `WebcamViewer.ipa`.

## Как поставить на iPhone

1. Подключи iPhone кабелем, открой **Sideloadly**.
2. Перетащи `WebcamViewer.ipa` на иконку IPA, выбери свой Apple ID, **Start**.
3. На iPhone: **Настройки → Основные → VPN и управление устройством** →
   выбери свой Apple ID → **Доверять**.
4. Если попросит — включи **Режим разработчика** в
   **Настройки → Конфиденциальность и безопасность**, перезагрузи телефон,
   подтверди включение.

## Как добавить свои камеры

Открой `Sources/WebcamViewer/Webcam.swift` и добавь строку в список
`sampleWebcams` — нужны только название, место, ссылка на страницу камеры
и `hasAudio` (ставь `true` только если сам проверил, что звук там есть).
